## Verify by running

A claim is verified only if you ran something and saw the result. Reading code, trusting the developer's summary or remembering that tests passed earlier does not count. If a command cannot run in this environment, say that plainly and mark the criterion `unverified` instead of passing it.

Tests that already failed before the change are not this change's fault. The brief lists the baseline. Report new failures, and note baseline failures separately.
